What the role covered

At Egrove Systems, I built web scraping tools using Python, Selenium, and BeautifulSoup to automate data collection that had previously been done by hand. That cut down manual research time for the team significantly and gave them a repeatable pipeline instead of one-off lookups.

Beyond scraping

I also contributed to internal web development and automation testing efforts, which meant working on the reliability and performance of internal applications rather than just the tools that fed them data.

Why it matters to me

This internship was my first real exposure to treating data collection as an engineering problem — reliability, error handling, and repeatability, not just "does the script run once." That mindset carries directly into how I approach data analysis now.
